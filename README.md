# Lock In

A colorful, responsive focus app for tasks, priorities, due dates, a timer, and clocks for five cities. It runs as a static webpage: no account, server, build step, or third-party JavaScript is required.

**Live website:** <https://rajeshwar01-01.github.io/focus-todo-list/>

## Features

- Add, edit, complete, search, filter, and delete tasks
- Set a task priority and optional due date
- Choose a task for a 1–180 minute focus session
- Pause, resume, and reset the timer; its countdown stays accurate when you switch tabs
- View the current time in New York, London, Mumbai, Tokyo, and Sydney
- Responsive layout, keyboard focus indicators, and reduced-motion support
- Store tasks in this browser on this device using local storage

## Run locally

Open `index.html` in a modern browser. No dependencies or build command are needed. The interface uses system fonts and CSS effects, so the app does not depend on external assets to render.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Select **Deploy from a branch**, choose `main` and the `/ (root)` folder, then save.
3. Open <https://rajeshwar01-01.github.io/focus-todo-list/> after the Pages deployment completes.

## Privacy

Tasks stay in the browser's local storage and are not uploaded to an account or server. They are available only in the browser profile and device where they were added. Clearing that browser's site data removes them.
