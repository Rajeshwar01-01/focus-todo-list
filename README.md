# Focus To-Do

A responsive browser-based to-do app with a focus timer and world clock.

## Features

- Add, edit, complete, search, filter, and delete tasks
- Set task priority and due date
- Use an animated focus timer
- View live clocks for New York, London, Mumbai, Tokyo, and Sydney
- Save tasks in the current browser using local storage

## Run

Open `index.html` in a browser. No build step is required. Google Fonts, Phosphor Icons, and the background video load from their provided external URLs, so those visual assets need an internet connection.

To publish with GitHub Pages, set the repository's Pages source to the `main` branch and the root folder.
